# Customer Shopping Behavior Analysis

## Overview

An end-to-end data analytics project focused on analyzing customer shopping behavior using Python, PostgreSQL, and Power BI. The project involves data cleaning, SQL-based analysis, and interactive dashboard development to explore customer purchasing patterns, product performance, subscription behavior, and revenue trends.

## Tools & Technologies

- Python (Pandas)
- PostgreSQL
- SQL
- Power BI

## Project Workflow

### 1. Data Cleaning & Preprocessing
- Loaded and explored the customer shopping dataset using Pandas.
- Handled missing review ratings using category-wise median imputation.
- Standardized column names for consistency.
- Created customer age groups using quartile-based segmentation.
- Converted purchase frequency categories into approximate days.
- Identified and removed redundant columns.

### 2. SQL Analysis
Performed customer and business analysis using PostgreSQL, covering:

- Revenue generated by male and female customers.
- Customers who used discounts and spent above the average purchase amount.
- Top-rated products and products with the highest discount rates.
- Average purchase amounts across shipping types.
- Spending patterns and revenue contribution by subscription status.
- Customer segmentation into new, returning, and loyal customers.
- Top-performing products within each category.
- Subscription behavior among repeat buyers.
- Revenue contribution across different age groups.

### 3. Power BI Dashboard
Developed an interactive dashboard to visualize customer shopping behavior and business performance, enabling exploration of purchasing trends, customer segments, and key business metrics.

## How to Run

1. Clone this repository.
2. Install the required Python libraries:

   pip install pandas sqlalchemy psycopg2-binary

3. Set up a PostgreSQL database.
4. Update the database connection credentials in Customer_Behavior.py.
5. Place the CSV dataset in the appropriate working directory.
6. Run Customer_Behavior.py to clean the dataset and load it into PostgreSQL.
7. Execute the queries in Customer_Behavior.sql.
8. Open Customer_Behavior.pbix in Power BI Desktop to explore the dashboard.
