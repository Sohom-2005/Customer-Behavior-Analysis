
# Customer Shopping Behavior Analysis

## Overview

An end-to-end data analytics project focused on understanding customer shopping behavior, purchasing patterns, and business performance. The project combines Python for data cleaning and preprocessing, SQL for business analysis, and Power BI for dashboard development to explore customer preferences, spending patterns, and purchasing trends.

## Tools & Technologies

- Python
- Pandas
- SQL
- Power BI

## Project Workflow

### 1. Data Loading & Exploration

- Loaded the customer shopping behavior dataset using Pandas.
- Examined dataset dimensions, structure, and key variables.
- Explored customer demographics and purchase-related information.

### 2. Data Cleaning & Preprocessing

- Cleaned and prepared the dataset using Pandas.
- Handled missing values and standardized data where required.
- Prepared the dataset for further analysis.

### 3. SQL Analysis

- Used SQL queries to analyze customer purchasing behavior.
- Examined spending patterns and customer segments.
- Analyzed product performance and subscription-related behavior.

### 4. Power BI Dashboard

- Developed an interactive dashboard to visualize customer shopping behavior.
- Presented key metrics and business insights through charts and KPIs.
- Explored purchasing patterns, customer demographics, and revenue trends.

## Key Analysis Areas

**Customer Behavior**
- Analyzed customer purchasing patterns and spending behavior.
- Explored differences between customer segments.

**Product & Purchase Analysis**
- Examined product performance and purchasing trends.
- Analyzed customer ratings and discount-related behavior.

**Revenue & Subscription Analysis**
- Explored revenue patterns across customer groups.
- Examined subscription-related purchasing behavior.

**Customer Demographics**
- Analyzed shopping behavior across demographic groups.
- Explored differences in spending patterns.

## Dataset

The project uses a customer shopping behavior dataset containing customer demographics, purchase details, product information, and shopping-related attributes.

## How to Run

### 1. Install Dependencies

    pip install pandas numpy

### 2. Run the Python Script

    python Customer_Behavior.py

Ensure that the customer shopping behavior CSV file is available in the appropriate working directory.

### 3. SQL Analysis

Open the SQL script in your SQL environment and execute the queries to perform the analysis.

### 4. Power BI Dashboard

Open the `.pbix` file in Power BI Desktop to explore the interactive dashboard.
